  • Đang chỉnh logic và cần phản hồi nhanh.
  • Cần đặt breakpoint / inspect biến.
  • Muốn chạy test và lint liên tục.

Cách 2 · Container runtime

Môi trường đồng nhất cho cả đội

Reproducible 
# Build và chạy
$ docker compose up --build

# Chạy nền
$ docker compose up --build -d

# Xem trạng thái và logs
$ docker compose ps
$ docker compose logs -f api

# Dừng container
$ docker compose down

Compose đã lo sẵn

  • Build image từ Dockerfile multi-stage.
  • Đọc biến môi trường từ .env.
  • Map 8000:8000 và mount ./logs.
  • Health check mỗi 30 giây.

Runtime image tối giản, chạy bằng appuser — không chạy root.

Chạy ứng dụng06 / Docker

Chọn công cụ theo mục đích

Local hay Docker?

Dùng cả hai

Local

Fast feedback
  • Reload nhanh khi sửa Python.
  • Dễ debug, test, profile.
  • Dùng trực tiếp toolchain trên máy.
  • Có thể khác môi trường của đồng đội.

Tốt nhất cho: phát triển hằng ngày.

Docker

Same runtime
  • Dependency và Python version nhất quán.
  • Dễ chia sẻ lệnh chạy cho cả đội.
  • Gần với môi trường triển khai/chấm hơn.
  • Build lại chậm hơn local.

Tốt nhất cho: integration & pre-submit.

Phát triển solution13 / Customization

Execution contract

Đừng phá contract của evaluator

input → output 
# Chạy solution giống evaluator
$ ./scripts/run.sh \
    --input data/public \
    --output outputs/result.json

# Kiểm tra artifact
$ test -f outputs/result.json
$ python -m json.tool outputs/result.json

Đọc từ input directory

Không giả định đường dẫn cố định trên máy cá nhân.

Troubleshooting · phần 1

Các issue thường gặp

Symptom → action
Triệu chứng Nguyên nhân thường gặp Cách xử lý nhanh
ModuleNotFoundError: main Chạy sai thư mục / thiếu app-dir Đứng tại repo root, thêm --app-dir src
Address already in use Port 8000 đang bị chiếm Tắt process cũ hoặc dùng --port 8001
.env file not found Chưa tạo file runtime config cp .env.example .env
Docs mở nhưng “Failed to load” API chưa chạy / sai port / CDN bị chặn Thử /openapi.json và health trước
401 Unauthorized Sai email/password portal Kiểm tra PORTAL_EMAIL, PORTAL_PASSWORD
503 Portal unavailable Sai base URL hoặc portal không reachable Kiểm tra PORTAL_BASE_URL từ đúng runtime
pytest treo ở route test Local đang dùng Python 3.13 Dùng Python 3.12 như Docker runtime

Troubleshooting · phần 2

Trong Docker, localhost ≠ máy host

Network boundary
API containerlocalhost:8000
×
Portal on hosthost port 8000

Chọn URL container truy cập được

PORTAL_BASE_URL=http://<reachable-host>:8000/v1

  • Portal remote: dùng hostname/IP được cung cấp.
  • Docker Desktop: thường dùng host.docker.internal.
  • Linux: có thể cần mapping host-gateway.

Troubleshooting17 / Docker networking

Security & submission packaging

.env được đóng gói khi submit

Know what ships
WHY

Portal cần config để chạy source

Archive service cố ý force-include .env, dù file này bị Git ignore, để evaluator chạy trong sandbox sạch.

Chỉ dùng credential dành cho team/hackathon.

DO
  • Giữ .env ngoài Git.
  • Review biến môi trường trước khi submit.
  • Dùng secret đúng phạm vi, có thể rotate.
DON'T
  • Không đặt personal token / cloud key không liên quan.
  • Không copy credential production cá nhân.
