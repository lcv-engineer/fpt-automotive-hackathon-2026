🔌 3. Chuẩn bị môi trường phát triển

🧪
Android Studio + Emulator
Bản mới nhất, Automotive system image API 33+. Dùng để code/compile nhanh, không cần trùng version với CarSky.
☕
Java / Kotlin · Gradle
Ngôn ngữ và build system chuẩn cho AAOS app.

Kết nối Android Studio tới AAOS thật đang chạy trên CarSky:

1
Connect Device
Rework UI → Devices → Connect vào Device của đội (Room do team hạ tầng deploy).
2
Mở ADB Tunnel
Nút mở tunnel trong panel Devices (hoặc vm_tunnel_open qua MCP/API) → nhận cổng cục bộ, vd localhost:5038.
3
adb connect
adb connect localhost:5038
adb devices
4
Debug trong Android Studio
Chọn thẳng device này như một thiết bị adb bình thường — Run/Debug, breakpoint, Logcat.
Lưu ý ADB Tunnel là phiên tạm — mất kết nối thì mở lại tunnel + adb connect lại, không cần deploy lại Room.

🧩 4. Các API/thành phần cốt lõi cần nắm

🧩
android.car.*
Package gốc Car API — entry point Car.
📡
CarPropertyManager
Đọc/ghi Vehicle Property, đăng ký callback realtime.
🔊
CarAudioManager
Audio zone & audio focus cho media/voice app.
🚧
CarUxRestrictionsManager
Giới hạn thao tác khi xe đang chạy (Driver Distraction).
🩺
CarDiagnosticManager
Đọc DTC / dữ liệu chẩn đoán OBD-II.
🔑
VehiclePropertyIds
Hằng số ID của từng Vehicle Property.
CarPropertyManager carPropertyManager =
    (CarPropertyManager) car.getCarManager(Car.PROPERTY_SERVICE);

carPropertyManager.registerCallback(callback,
    VehiclePropertyIds.PERF_VEHICLE_SPEED,
    CarPropertyManager.SENSOR_RATE_NORMAL);

❓ 11. Câu hỏi thường gặp

App không nhận được Vehicle Property mong muốn?

Kiểm tra property đã được wire trong blueprint chưa (xem widget Signal Watch) — nếu chưa, báo team hạ tầng, không debug tiếp phía app.

Không thấy device trong adb devices?

Kiểm tra ADB Tunnel còn mở không; mở lại tunnel và adb connect lại. Không cần deploy lại Room.

Sửa code xong nhưng VM không có gì thay đổi?

Sửa code app → chỉ cần cài lại APK. Đổi topology/blueprint → cần team hạ tầng redeploy (ngoài quyền đội thi).

2 Đưa application lên AAOS trên môi trường CarSky (Deploy)

Từ bản build cuối cùng đến app chạy được, demo được, đúng chuẩn trước BGK.

📘 1. Giới thiệu

Đảm bảo ứng dụng chạy ổn định và demo được trực tiếp trên Device/Room mà CarSky đã cấp cho đội, đúng quy trình nộp bài.

✅ 2. Yêu cầu trước khi deploy

  • Build thành công, không lỗi biên dịch
  • Đã test qua ADB Tunnel trực tiếp trên Device của đội
  • Tự review: chức năng chính đúng, UI không vỡ, không crash khi bơm tín hiệu

🛠️ 3. Build & Package

🧪
Debug build
Test/demo nhanh, lặp lại nhiều lần.
./gradlew assembleDebug
🚀
Release build
Nếu đề bài yêu cầu app đã ký.
./gradlew assembleRelease

🟢 4. Xác nhận Room/Device đã sẵn sàng

🖱️
Qua UI
Tab Deployments trong Nydus, hoặc panel Dashboard.
⚙️
Qua API/MCP
deployment_status(roomId) — mọi node phải Running.
Lưu ý Device lỗi/chưa deploy → liên hệ team hạ tầng. Đội thi không tự deploy lại blueprint nếu không có quyền editor/admin.

📲 5. Cài đặt app lên AAOS VM (Skycraft)

🔌
Cách A — ADB Tunnel
Khuyến nghị khi lặp lại nhiều lần / dùng Android Studio.
adb connect localhost:<port>
adb install -r app-release.apk
adb shell pm list packages | grep <package>
💻
Cách B — Widget ADB
Terminal ADB ngay trên Rework UI, không cần cài adb cục bộ. Chạy lệnh cài đặt trực tiếp trong đó.
Đề bài nhiều display / system app Cấu hình display nằm trong blueprint Skycraft node — đội thi không tự thêm display; cần xác nhận trước với team hạ tầng (vd Đề 4 — Multi-Display).

📤 8. Nộp bài (Submission)

  • Push code lên Git repository (GitHub/GitLab) trước deadline
  • README: mục tiêu, kiến trúc, hướng dẫn build, hướng dẫn cài lên CarSky, danh sách property đã dùng
  • Không sao chép code; ghi rõ nguồn thư viện mã nguồn mở

🗓️ 10. Timeline & deadline tổng hợp

Hoàn thành code→ Deploy thử & smoke test→ Quay video dự phòng→ Demo / nộp bài

📋 11. Phụ lục: Checklist nộp bài

  • Build release/debug không lỗi
  • Đã cài và test trên đúng Device của đội trên CarSky
  • Đã smoke test qua Signal Watch/GPIO Panel, không crash
  • Đã quay video demo dự phòng
  • Repo Git đầy đủ README, đã push trước deadline
  • Không vi phạm quy định sao chép code
